Accessibility

This shop was built for disabled shoppers first, not retrofitted for them afterwards. This page is the honest account: what each feature does, who it is for, where it works, and what is still missing.

Speech

Read aloud

Blind and low-vision shoppers · reading difficulties · fatigue

Turn it on and the page speaks whatever you point at or tab to, with the spoken block highlighted as it reads. Every piece also gets its own Listen button, which reads a single composed sentence: what it is, what it costs, how it fastens, what it is made of, where it came from, and which of your quiz answers it matches. That sentence is assembled from the item's own record, so it can never fall out of step with what is on screen.

Uses the browser's built-in speech synthesis. Works in Chrome, Edge and Safari. Firefox needs a system voice installed. If no voice is available the control says so rather than failing quietly. This is not a replacement for a screen reader — the page is built to work properly with one.

Audio guide

Blind and low-vision shoppers · anyone who would rather listen than read

A five-chapter spoken walkthrough with play, pause, chapter skip and a speed control. The full transcript sits underneath and highlights the chapter being read; you can jump to any chapter by clicking its text. There is no audio file — the chapters are spoken by your own device voice, which means they always match the transcript exactly and respect the voice and rate you chose.

If speech is unavailable the transcript is shown as a complete standalone document.

Voice control

Limited hand mobility · tremor · RSI · anyone shopping hands-free

Answer the quiz and move around by speaking. Say an option's name to select it, or use next, back, bag, close, stop, settings, bigger, smaller, dark, light, contrast. A live panel shows what was heard, so a misrecognition is visible rather than silent.

Uses on-device speech recognition in Chrome, Edge and Safari; the control is disabled with an explanation elsewhere. Needs microphone permission. We never record, store or transmit audio.

Sound

Sound cues

Blind and low-vision shoppers · anyone who misses silent state changes

A short distinct tone when something is added, removed, advanced or rejected, so a confirmation you cannot see still registers. Volume is adjustable and the whole thing can be switched off. The tones are generated in the browser, so there is no download and no delay, and every cue is paired with a screen-reader announcement — sound is never the only signal.

Seeing

Three themes, text size, line and letter spacing

Low vision · light sensitivity · dyslexia · astigmatism

Light, dark and a genuine high-contrast theme with a separate flat palette and thicker rules, not just darker text. Text scales from 90% to 200%, and line spacing and letter spacing are independently adjustable. The whole layout is built on relative units, so nothing overlaps or clips as the type grows.

Dyslexia-friendly font, link underlines, bold focus ring, reading ruler

Dyslexia · low vision · attention and tracking difficulties

OpenDyslexic with opened-up word spacing and a narrower measure. Every link forced to underline, so colour is never the only marker. A 4-pixel high-visibility focus ring for keyboard use on a bright screen. A reading ruler that follows the pointer and dims everything above and below the line you are on.

Catalogue plates

Low vision · slow connections

Each piece is drawn as a vector silhouette filled with a photograph of the real textile. Because the plate is vector, it stays sharp at 200% text size instead of blurring, and it re-inks itself for the dark and high-contrast themes. The colourway is also stated in words and shown as a swatch, so the drawing is never the only evidence of what colour something is.

Movement and motor

Reduce motion

Vestibular disorders · migraine · motion sensitivity

Removes every fade, slide and smooth scroll. Set automatically if your operating system already asks for reduced motion, and the page keeps following that setting if you change it while the page is open.

Large touch targets

Tremor · limited dexterity · touch screens

Grows every control to at least 48 px with more space between them. Without it, controls already meet 44 px.

Dressing filters

Limited hand function · one-handed dressing · wheelchair users · sensory sensitivity

The one feature here that is about the clothes rather than the interface. Filter the collection by how a piece is put on: pulls on with no fastenings, can be fastened one-handed, cut for seated wear, no sewn-in tags. Every card states its fastenings, and the product passport spells out the details — button diameter, zip-pull size, whether a coat's buttons are magnetic. This information exists in the database as structured fields, not as marketing copy.

Keyboard

Everything works from the keyboard. Dialogs trap focus, close on Escape and return focus to whatever opened them. There is a skip link, and headings move focus when a step or section changes. Shortcuts are ignored while you are typing in a field.

Privacy

Every setting is stored in this browser's local storage and nowhere else. Nothing is sent to a server, because there is no server. Speech recognition runs on your device. Read aloud and voice control both start switched off after a reload, because a browser will not start audio or open a microphone without you asking first — your saved preference is kept, but the feature waits for you.

What is still missing

An accessibility page that only lists wins is not an accessibility page. Known gaps:

  • No screen-reader testing report yet. The markup uses correct landmarks, live regions and roles, but it has not been run through a formal NVDA, JAWS or VoiceOver pass.
  • No translation or plain-language alternative. The reading level is moderate, not simple.
  • Voice control recognises English only, and matches option labels literally.
  • Checkout is not connected, so the hardest part of an accessible purchase — payment, address entry, error recovery — is untested.
  • The dressing information is authored by hand per item. At real catalogue scale it needs to come from the supplier's own data or a Digital Product Passport feed.
